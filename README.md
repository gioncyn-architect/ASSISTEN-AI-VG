# 🏛️ ASISTEN AI VG - ARCHITECT PRO

**ASISTEN AI VG** adalah aplikasi asisten digital modern yang dirancang dengan estetika mewah dan fungsionalitas tinggi. Mengusung konsep **Bring Your Own Key (BYOK)**, aplikasi ini memberikan kendali penuh kepada pengguna atas kunci API mereka sendiri.

## ✨ Fitur Utama
- 🔑 **BYOK (Bring Your Own Key):** Mendukung 10+ provider AI (Gemini, Groq, Mistral, OpenRouter, dll).
- 📱 **Mobile-First Design:** Dioptimalkan khusus untuk pengguna smartphone menggunakan Acode & Termux.
- 🎨 **Luxury UI:** Antarmuka elegan dengan 5 pilihan tema mewah (Gold, Emerald, Sapphire, Ruby, Silver).
- 🚀 **PWA Ready:** Dapat diinstal langsung di Android seperti aplikasi native.
- 🎙️ **Voice Command:** Dilengkapi fitur pengenalan suara untuk input perintah.

## 🛠️ Teknologi
- **Frontend:** HTML5, CSS3 (Modern Flexbox), JavaScript (Vanilla)
- **Icons & Fonts:** Google Fonts (Inter, JetBrains Mono, Playfair Display)
- **Mobile Support:** Acode Editor, Chrome Mobile PWA

## 📦 Cara Instalasi
1. Clone repositori ini.
2. Masukkan file `index.html`, `manifest.json`, `sw.js`, dan `icon-512.png` ke folder root.
3. Jalankan melalui server lokal atau GitHub Pages.
4. Buka di Chrome Android, lalu pilih **"Instal Aplikasi"** untuk menjadikannya PWA.
